# Prerequisites

All practical sessions run on **your own laptop**, in a [separate user account](separate-account.md)
just for the course. Please install everything below **before Monday 30 November 2026**, then run the [setup check](check.md). It takes roughly 1–2 hours,
most of it waiting for downloads.

!!! tip "Stuck? Don't worry."
    Monday's [Environment setup and terminal essentials](../workshops/environment-setup.md) session
    (11:30–12:45) is there to fix whatever did not work. Write down the exact error message, or
    take a screenshot, and bring it along.

## Your laptop

- macOS 12+, Windows 10/11 (64-bit) or a recent Linux distribution (e.g. Ubuntu 22.04+)
- **Administrator rights** to install software. On an institution-managed laptop, ask your IT
  department in advance.
- At least **15 GB of free disk space** and **8 GB RAM** (16 GB recommended for the
  single-cell sessions)
- A charger. Sessions run all day.

On each page below, pick your operating system once and the choice applies across all pages.
