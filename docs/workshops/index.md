## How the week fits together

| Day | Theme | Hands-on |
|---|---|---|
| **Mon** | Foundations | Laptop setup and terminal → Git review loop → R refresher |
| **Tue** | Reading code, and coding with AI | Python → AI-assisted coding I and II |
| **Wed** | AI-assisted science | Agents, skills and MCP for scientific work |
| **Thu** | Real data | Imperfect clinical data → single-cell analysis with an agent |

Every session builds on the previous one. Git comes first because it is the safety net for all
AI-assisted work that follows: **commit → let the agent work → read the diff → keep or revert.**
